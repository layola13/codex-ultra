Welcome to **codex-ultra**. This software is a purely locally deployed interactive workbench and local API scheduling tool. We place a high priority on protecting user privacy and data security. This Privacy Policy outlines how data is handled during local operation.

---

## I. Fully Local Deployment & No Remote Control Principles

* **Local-First Privacy**: All software components, WebSocket bridges, and workbench services run strictly on your local device. Your API Keys, tokens, configuration credentials, conversation logs, and terminal history are saved locally and never uploaded to central cloud servers.
* **No Remote Control**: This software contains **NO remote control mechanisms, backdoors, or remote administration capabilities**. Neither the maintainers nor any third party possesses remote access or control over your computer.
* **No Permission Reallocation**: Designed solely for single-user local operation without multi-tenant management or delegated access control.

---

## II. Network Connections & Third-Party APIs

* **Outbound Scope**: Any external network connection initiated by or through this software is **strictly limited to user-configured third-party API providers** (e.g., OpenAI, Anthropic, Google) or user-configured storage/note integrations (e.g., WebDAV, S3, Notion).
* **No Traffic Monitoring**: The software maintains no central servers to monitor, intercept, or proxy your network traffic.

---

## III. Diagnostic & Operational Telemetry (Configurable)

To ensure system stability and compatibility, limited anonymized diagnostic logs may be generated locally:
* **Version & Crash Logs**: Used purely for local troubleshooting and stability enhancements.
* **Privacy Commitment**: Diagnostic logs **never contain** API Keys, prompts, code, or personal identifiable information.
* **Control**: You may toggle telemetry on or off at any time under `Settings > Privacy & Safety`.

---

## IV. Computer Malware, Ransomware & Local Security Disclaimer

* **Local Security Responsibility**: Data corruption, privacy breaches, or financial losses caused by computer virus infection, malware, ransomware file encryption, operating system vulnerabilities, or network hacking are **completely unrelated to this software**.
* **Zero Maintainer Liability**: Maintainers and developers **assume no liability whatsoever** for local malware infections, ransomware encryption, or system security breaches. Users are solely responsible for maintaining local firewall, anti-virus, and security protections.
